# Growmory Apple 风格界面重做

日期：2026-11-05。

## 设计依据

使用已安装的 `frontend-design` skill。视觉参照 SuYue 个人主页当前的 `public/assets/product-design.css`，将其浅色、大标题、克制配色与留白转化为适合日常操作的工作台，而非宣传首页。

基础颜色：白色 `#fff`、浅灰 `#f5f5f7`、正文 `#1d1d1f`、辅助文字 `#6e6e73`、分隔线 `#e5e5e9`、操作蓝 `#0071e3`。采用 Apple 系统字体栈，标题、阅读、列表和元信息分别使用不同字号与字重。

## 重做范围

- 重写 `src/style.css`，移除 `src/workspace.css` 及其导入，结束多层覆盖的旧样式结构。
- 网站导航、可折叠产品列表、产品功能中栏与正文采用统一宽度变量。桌面维持三栏，手机改为网站菜单与横向产品导航。
- 工作台重新组织为真实工作状态、待处理、进行中版本和产品登记列表。没有增加示例经营数据。
- 产品目录改为清晰的产品身份列表；产品概览改为资料/版本/内容入口、当前事项和基础信息。移除重复的产品名称区与相同占位文案。
- 资料库采用统一工具栏、筛选、目录、归属及状态列表；阅读与编辑有独立层级。
- 版本详情以当前阶段为主，桌面阶段导航留在中栏；移动端提供阶段切换。统一多语言说明、AI 辅助、发布检查和知识建议的呈现。
- 表单、编辑抽屉、确认框、资料历史、差异审核、内容、待办、设置、商店、ASO 与趋势数据组件使用统一的基础控件和版式。
- 资料库范围独立保存为 URL 的 `library` 参数，不再占用产品范围；保留产品内营销内容栏目刷新恢复。
- 开发热更新复用 React 根节点，避免反复调整界面时重复创建根节点。
- 不更改后端协议、商业规则或真实资料，不触发 AI 生成、商店写入或真实发布。

## 验证

- TypeScript 与 Vite 构建通过。
- `npm test` 的 44 项既有测试通过，覆盖本地保存、通用资料、目录隔离、MCP、版本说明、商店和 ASO 等逻辑。
- 通过 CUA 实际浏览器检查 1440、1024、768、390、320px 下的工作台、资料库、内容、待办，以及产品内资料、版本和营销内容，共 35 组，无页面横向溢出。
- 另检查 320px 下设置的三个分组、版本详情与多语言编辑抽屉，无页面横向溢出。
- 确认通用资料筛选后返回工作台，产品范围仍为 `all`；资料库自身范围仍能保留。
- 实际查看工作台、产品概览、资料库、版本详情和多语言编辑抽屉，按截图纠正重复阶段栏、标题及导航层级。
- 未运行旧 `test:browser` 全流程脚本；本轮没有重新验证真实 AI 输出、Apple 远端写入或社交平台发布。
