# 小红书笔记身份与来源隔离（2026-11-06）

## 已实现

- 小红书 explore、discovery/item 链接按笔记ID规范化，访问参数不作为身份。同标题不同ID分别保存，标题更新保留在各次快照。
- 不再按标题或发布时间自动合并报表。无链接报表保留原externalId（标题+完整发布时间生成的报表行标识），作为待关联项。
- 数据总览提供报表关联面板：按完整发布时间、标题排序候选，同账号选择真实原帖，确认/更正/解除映射。没有采集到的原帖不能凭空绑定。
- reportLinks按账号+报表externalId持久保存，后续同标识报表复用映射。修改标题导致报表标识变化时，会产生新的待关联项，仍需确认，避免冒险匹配。
- 原始快照按账号、身份、来源、观察时间（报表使用文件哈希）、统计周期存储；重复同一观察可更正，但不会将不同观察的数据混写。
- 汇总按指标选取最新非空值（先统计截止日，再观察时间）；0为实际值，null不作为有效值。区间必须两端相同，累计可展示不同日期的最新可用指标。
- 每个指标保留原始快照ID、来源说明、观察时间、截止日；无自动跨时间计算转化率。历史查看原始记录。
- 待关联报表不计入顶部内容和指标总览。删除汇总行会明确提示，并删除其包含的原始记录。

## 兼容与限制

不自动改写现有数据。旧逻辑已混合的快照无法推断每个字段的真实时间，需要原报表与重新采集来重建；本改动只能保证之后的来源隔离。旧记录已有链接时按该身份展示，无法自动证明历史关联是否正确。报表映射不是标题永久身份；标题变化后的新报表行需要重新确认。完全相同标题与秒级发布时间的重复报表行仍由导入校验拒绝，需要原始笔记ID才能消歧。

结论：现有MCP Cookie不足以访问创作者后台；需要独立完成创作服务平台登录，才能进一步验证是否能稳定读取笔记ID、曝光、观看、统计周期和分页。当前未验证这些指标可采集，也没有实现后台自动采集器。不能据登录页结论承诺可完全替代导出。
